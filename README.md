# Pixel Cafe

## Description
This is a project for the Order Up Quest for Hackclub Pixl. You start with a randomly generated budget and you try to spend it all on donuts and drinks at the Pixel Cafe. My main goals for this website was to learn Astro and Tailwind(this is my first time using both) and get more comfortable with JS.

## How it works 
1. Roll for your budget. This is the unique part of this cafe website. The budget ranges from $10 to $200, and iti s how much money you have to spend at the cafe. You cannot buy the items if it exceeds your budget, so you have to manage your cart well to get everything you want.
